# 🥇 I worked on features that allow investors to:
- View available investment projects
- Manage their account balance
- Deposit and withdraw funds
- Make investments in projects
- View and manage existing investments
- Interact with project-related functionality
- Communicate with administrators through real-time chat
- Contributed to both the frontend user interface and the backend services supporting these features.

## 🕴️Investor Features 
- Account and wallet management: display investor account balance, deposit funds, withdraw funds and manage wallet-related operations.
- Investment Management: browse available projects, submit investments, view existing investments and access project information relevant to investors
- Real-Time Communication: investor-to-admin chat functionality and real-time messaging using WebSocket-based communication.

### 🛠️ Technologies 
- Frontend: React, JavaScript/JSX, React Router, Vite and HTML/CSS.
- Backend: Java, SpringBoot, Rest APIs, Spring Data JPA and Maven.
- Database: H2 Database.
- Communication: WebSocket, Stomp and SockJS.
